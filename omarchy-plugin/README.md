# Optional Omarchy launcher plugin

Install the desktop app first. Copy this folder to `~/.config/omarchy/plugins/rickndanger.dog-walker/`, then add `rickndanger.dog-walker` to the bar using Omarchy's bar settings. Plugin files hot-reload. This widget launches the app; it does not run jobs or read your project files.

This is a user-owned plugin prototype for the installed Quickshell-based Omarchy shell. It is not an official Omarchy distribution package, and older Waybar-based versions are not supported by this widget. Never copy it into `/usr/share/omarchy/`.
