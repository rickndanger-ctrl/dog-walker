How Handler works
  1. 1. Start on your computer. Give your agent the form and task. Import its completed .dogwalk file yourself, or have the agent save it directly in Handler's inbox. Review the plan, choose an ordinary project folder, then press Start walk. Git history is prepared locally; no GitHub account is needed. Depositing or importing alone does not run it.
  2. 2. Watch from here. Keep Tailscale connected, the computer awake, and the desktop app open. The first local-model step can take a few minutes. This phone follows the walk selected on the desktop.
  3. 3. Read before approving. At Needs your review, check the summary, allowed files, and test results. Approve & continue accepts this checkpoint after checks run again. Retry this step requests the authored correction. Failed checks cannot be approved away.
  4. 4. Pause or resume. Pause walk retains partial work. Resume walk continues the selected paused walk. An interrupted step may ask for an explicit retry. Disconnected phones cannot send or queue actions.
  5. 5. Review completed work. On the computer, use Open results. Protected copy keeps edits in a separate workspace; review and copy or merge changes yourself. Start new jobs and choose saved walks on the desktop.
